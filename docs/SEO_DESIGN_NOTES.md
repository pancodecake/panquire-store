# SEO design direction

Preserve the product-led Panquire storefront. Tokens: carbon #08090B, surface #151619, border #34363B, text #F3F3F1, secondary #B8B9BD, bronze #A97832. Use the existing semantic CSS variables, Montserrat headings and Work Sans body text. No new font downloads or autonomous motion.

Collection structure: existing heading and product grid, then an accessible three-column comparison table; below it, left-aligned guidance and native disclosure FAQs. Desktop reading width stays under 72 characters. On mobile the model table remains three columns with wrapped labels, while guidance becomes one column. Buttons retain the existing pill shape and focus treatment.

Product pages receive a short model-specific selection section and contextual links, without another H1 or replacing purchase components.

Review against brief: revised an initial repeated-card concept into a shared comparison table and two quiet reading columns. Product differences carry the hierarchy; decorative labels, numbered markers and motion are unnecessary. All new content is server rendered. Prices come from product objects and performance values from existing model metafields.
