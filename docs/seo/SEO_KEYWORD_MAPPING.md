# Implemented keyword ownership

US English strategy from the supplied DataForSEO research. Volumes are individual historical estimates; variants are not summed and KD=0 is not proof of an easy ranking.

| URL | Primary keyword / intent | Supporting terms | Implementation |
| --- | --- | --- | --- |
| `/` | Panquire brand navigation | Panquire electric dirt bikes, mini electric motorcycles | Brand metadata, category CTA, organization identity |
| `/collections/electric-dirt-bikes` | Electric dirt bike for adults (40,500 avg/month) | For sale, affordable, under $3,000 / under $2,000 shopping | Existing grid, buying guide, current-price table, conditional USD budget text and FAQs |
| `/products/t-01` | 60V electric dirt bike (2,400) | Panquire T-01, 50 mph research theme | Specific metadata, model-selection content and contextual links |
| `/products/t-02` | 72V electric dirt bike (4,400 average; latest source month 590) | Panquire T-02, 72V electric dirt bike for adults | Specific metadata, nominal-energy context, lower-priced model link |
| `/pages/compare` | Sur-Ron alternative (320) | Cheap/best alternative, budget buying comparisons | Existing interactive tool plus editorial tradeoffs and model table |
| Product FAQs / collection section | Ownership, range and fit questions | Charging, battery removal, warranty, maintenance | Supports the commercial owners; no universal parts landing page |
| `/products/t-03` | Existing mini electric motorcycle intent | Panquire T-03 | Own metadata preserved; breadcrumb and actual comparison price |
| Other collections/blog/business/policy pages | Existing page-specific purpose | No forced dirt-bike targets | Existing templates preserved; no duplicate landing pages |

Collection owns broad shopping; comparison owns alternatives/evaluation; products own models/configurations. A supporting mention does not assign a second primary owner. Dynamic USD budget text checks current prices/currency and does not promise a delivered total.

Internal path: homepage/navigation → collection → products; products → other model, collection, comparison, support; comparison → products and collection. Breadcrumbs reinforce relationships. Existing canonical handling remains; do not index every selector state as a separate landing page.

Deferred: original range/handling tests, electric-versus-gas cost article, first-hand independent reviews and native-language expansion. The 70 mph keyword, racing, road-legal and minor-targeting hypotheses are not product promises.
